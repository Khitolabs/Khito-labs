# Khito Labs

Física y cálculo para curiosos: página de estudio con resumen, simuladores interactivos, leyes y teoremas, ejemplos resueltos y ejercicios con resolución paso a paso.

Publicada con GitHub Pages: https://khitolabs.github.io/Khito-labs/

- `index.html`: la página (vistas por `#tema`).
- `aa/`, `c3/`, `dn/`, `ed/`, `ej/`, `fm/`, `np/`, `op/`, `te/`, `tm/`: módulos de cursos, laboratorios y ejercicios.
- `marca/`: logos y mascotas (Yoru y Asa).
